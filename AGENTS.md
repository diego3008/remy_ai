# remy.ai

_Agentic ai for restaurants_

remy is a new use case application for agentic AI that will allow me to explore new ways of building agentic solutions with different niches.

remy.ai will have it's core in langgraph to build its workflows.

## Project structure

```text
claude/
remy_ai/
├── src/
│   ├── graphs/ -> contains the langgraph graphs that will handle workflows
│   ├── models/ -> contains stablished models based in the API for database operations
│   │
│   └── nodes/ -> contains nodes for graph functionalities
├── .gitignore
├── Agents.md
├── langgraph.json
├── .env
└── README.md
```

You will be able to modify whatever is in remy_ai folder with my authorization.
